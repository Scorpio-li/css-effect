## css-effects-snippets(css动效合集)

- 项目路径: `css-effects-snippets/`
- 基于 Vue 的 CSS 动效合集，点击即可复制到剪贴板
- 包含 text / button / animation 三大类共 27 种动效：
  - text: borderLeftRight、siblingFade、borderFade、lineThrough、textTransformX、swingHorizontal、pulseAnim、visibleBorderLeftRight、magnifyText、borderMarker、buttonOverlay、horizontalOverlay
  - button: pulseBtn、radiusPulse、pressDownButton、arrowFromLeft、overlayLeftBtn、slideUpBtn、circleScaleBtn、pushUpBtn、snapLeftBtn、magnifyBtn、magnifyBorder
  - animation: donutSpinner、bouncingLoader、arrowBounce、arrowScrollDown
